I am creating an HTML based comic book called "The Chronicles of Enzo". I envision a single file HTML based reader application and a single file HTML based editor application, with, perhaps, a separate database file that contains image names and order, as they will appear in the reader application. The images themselves, will be in a subfolder called Images. The comic book will have a title page and corresponding title image,  chapter names (with or without corresponding chapter images), and individual pages, each containing an image from the Images folder, and perhaps a page number. Images will be stretched to fit the browser area, without changing the aspect ratio.

The Reader interface will have a navigation menu for Title, Chapter or Page, including next page and previous page.  The title page and some of the individual chapter or image pages may have more than one alternate images, which load randomly when the page is brought up. There may also be a button that switches to the next alternate image for that page. 

The editor application will have a thumbnail of all of the images in the Images folder (preferably sorted initially by date). These can be dragged and dropped into a particular page order after each particular chapter. The Title and chapter headers can be renamed and associated with one image or multiple alternate images. Each page can also have zero or more alternate images. Any unused images will be kept in a separate section as potential drop-ins for one of the sections in the comic book. There will be a commit button which will save the setup into the database, which will be accessed by the reader application.  The commit button should also create a backup of the database, prior to creating a new one. There shoul also be the ability to view the individual images full-size.
